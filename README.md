# Spectrite 1.21.1 — Señor de la Muerte y Monstruosidad de Spectrita

Minecraft 1.21.1 · NeoForge 21.1.172 · Java 21.
Dependencias: Soul Fire’d 6.1.0, Prometheus 1.2.5 y Cobweb 1.4.0.

Incluye el tier Señor de la Muerte, armadura y jefe 3D, seis estados de ataque y cuatro moldes de mejora por derrota con crédito del jugador. El molde no se puede fabricar ni duplicar mediante recetas. Las cuatro mejoras de armadura requieren un molde cada una.

Validación: 52 pruebas automatizadas correctas y 12 comprobaciones del cliente nativo. No se ha realizado una partida multijugador manual.

Instala el JAR en mods y sustituye la versión anterior de Spectrite; no mantengas dos versiones a la vez. Usa la misma versión en cliente y servidor. Revisa SHA256SUMS.txt para comprobar el archivo.
